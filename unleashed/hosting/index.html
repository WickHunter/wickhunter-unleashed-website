Scope

What's included, and what isn't.

Hosting covers the supported Unleashed installation. It isn't managed trading, and it isn't open-ended server administration.

Included

✓A private cloud server with Unleashed preinstalled and kept current through Unleashed's own signed in-app updater
✓HTTPS access to your dashboard
✓Initial OS hardening and ongoing security patching
✓A documented restart / reinstall path if something breaks
✓Billing and access support at admin@wickhunterunleashed.com

Not included

–Managed backups — retaining a suspended server for its grace period isn't a backup; export your settings before you need one
–Trading results, monitoring, or automatic trade recovery of any kind
–Custom Linux administration, or fixing changes made outside the supported configuration
–A guaranteed uptime figure — none is advertised, and none is implied
Region & security

Where it runs, and who can see your keys.

Two separate questions: can the server reach the exchanges you use, and can anyone at Wick Hunter Software see your credentials.

Region & exchange access

Every instance is created in a region every exchange Unleashed supports currently accepts API traffic from.
Before your instance is handed over, we run a live reachability check against each supported exchange's API from that exact server, and tell you if one doesn't respond.
This doesn't change your own account's eligibility. Access to any exchange still depends on that exchange's own KYC, residency, and eligibility rules for your account — region only affects whether the server itself can reach the venue's API.

Your exchange keys

You create restricted, trade-only API credentials on your exchange and enter them directly into your own hosted instance — the same as on a self-hosted install.
Wick Hunter Software never receives, transmits, or stores your exchange credentials. Staff cannot see them.
Every instance starts paused with a temporary password. You must set your own password before the instance connects to an exchange or trades.

If a hosting payment fails

Grace period, then suspension — nothing silent.

Hosting non-payment follows a fixed, disclosed timeline. It never touches your exchange account.

Timeline

Payment fails → automatic retries for 72 hours.
Still unpaid at 72 hours → the server is suspended (powered off). Nothing is deleted yet.
Reminder emails go out before the deadline, and again when the server is suspended.
Still unpaid 10 days after the missed payment → the server and its data are permanently deleted.
Pay at any point before deletion and the server is restored — bot management stays paused until you confirm it's safe to resume.
Suspension never closes your positions.Powering off the server stops bot management only. Any open positions or resting orders stay exactly as they are at your exchange until you act on them.
