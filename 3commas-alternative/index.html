Self-hosted software vs. a web platform

Wick Hunter Unleashed is software that runs on one private server. With self-hosting you install it on a supported VPS (Ubuntu 22.04 or newer, at least 1 GB of memory) and handle the server administration yourself; with managed hosting we provision the server, install Unleashed and email your dashboard address. Updates are signed and applied from inside the app. One server per licence.

3Commas is used through its website and mobile apps, and you link your exchange accounts to your 3Commas account. Which model suits you depends on whether you want to operate a server yourself, or prefer not to.

Where your exchange keys live

In Unleashed, your exchange API keys are stored on your own server. The connect guide is explicit about the trade-off: every running account's keys are decrypted together and held in memory for the life of the process, so the server should be secured accordingly. Both products ask for trading permission with withdrawals disabled.

Bot types for futures traders

Unleashed focuses on futures deal management. Its liquidation bots enter from liquidation activity, TV Signal enters from TradingView alerts, the Manual Bot manages trades you open yourself, and the Hedge Bot opens opposite-side tranches on a position that moves against you. Entries are managed with an optional DCA ladder, a take profit and an optional stop loss. Every bot needs the account in Hedge Mode.

3Commas lists DCA, Signal and Grid bots alongside SmartTrade and a trading terminal, and covers spot as well as futures. Unleashed does not offer spot trading or a grid bot.

Exchanges

Bybit, Binance and Bitget appear on both lists. Unleashed also supports Bitunix, Aster and WEEX. 3Commas' exchanges page also lists Hyperliquid, OKX, Gate, Kraken, KuCoin and Coinbase, which Unleashed does not support. If your account is on one of those, Unleashed is not an option for it today. See supported exchanges for the credentials each venue needs.

Pricing model

Unleashed is licensed software: Monthly, Yearly or Lifetime, and every plan includes the same bots, supported exchanges and updates. If a subscription lapses, the app keeps closing and protecting existing positions but opens nothing new until you renew. Current prices are in the plans section. 3Commas lists Starter, Pro and Expert tiers on its pricing page, with lower prices for annual billing.

Moving over

Use one automation system per exchange account, so two systems do not manage the same positions. If you already hold open positions when you connect an account, Unleashed offers to let the Manual Bot manage them or leave them alone. Start with the Quickstart.
