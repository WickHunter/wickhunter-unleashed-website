Getting started

Quickstart

From your welcome email to a first small, protected trade in seven steps.

Seven steps from purchase to a first small trade. Keep each step small: the goal is to see one deal open, get protected and close, not to make money on day one.

1. Open your dashboard

Managed hosting. You receive an email titled "Your Unleashed VPS is ready". Open the app address in it and sign in with the temporary Unleashed password from the email. The app then asks you to set your own password ("Set your password") before anything else. Bots stay paused until you connect an exchange and start them.

Self-hosted. You need a fresh Ubuntu 22.04 or newer VPS with at least 1 GB RAM and root access. Open the install page linked in your purchase email; it issues a fresh one-time install command each time you open it. Paste the command into an SSH session as root. It installs the app and HTTPS, prints your dashboard address and asks you to choose a password.

Tip. Bookmark the dashboard address. Keep your install link, licence and password private. Never re-run the installer to upgrade; updates are applied inside the app (Updates).

2. Create a trade-only API key

On the exchange, create a normal API key with read and trade permission only. Never enable withdrawals or transfers. Restrict it to your server's IP address if the exchange allows it.

3. Turn on Hedge Mode

Every bot needs the account in Hedge Mode (separate long and short positions). Some exchanges are switched for you; others you must set yourself while flat. See Hedge Mode.

4. Connect the account

Open Accounts → Add account, choose the exchange, paste the credentials and tick the market. Wait until the account card validates without a ⚠ warning.

5. Create one small bot

The simplest first test is a Manual Bot: one direction, one pair, DCA orders 0 (type 0), take profit on and stop loss on. Then open the smallest position the exchange allows. New bot forms start blank on purpose; every value is your choice.

6. Check it

  • Deals shows the deal, its owner, take profit and stop.
  • Activity explains anything the bot skipped or refused.
  • The exchange shows the same orders.

7. Know how to stop, then grow slowly

  • ⏸ Pause on a bot stops new trades. Open deals keep being managed.
  • To exit now, close the position at the exchange.
  • Turn on Discord alerts under Settings → Notifications (Activity & notifications).

Change one setting at a time. Read the page for any bot before you enable it.
