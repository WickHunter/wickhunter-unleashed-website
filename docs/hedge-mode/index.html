Hedge Mode

Why every bot needs Hedge Mode, and who switches it on each exchange.

Hedge Mode holds a long and a short on the same pair as two separate positions. One-Way mode is not supported. On a One-Way account the app refuses orders and says why.

  • Exchanges refuse a mode change while any position or open order exists, so close everything first.
  • Where the app switches for you, it waits until the account (or pair) is flat. If it stays blocked you get a HEDGE MODE BLOCKED notice naming what is still open.
  • Where you set it yourself, do it in the exchange's futures settings before you start any bot.

Who switches it

ExchangeHedge Mode
BybitSwitched for you, pair by pair, when that pair is flat
BinanceSwitched for you once all positions and orders are flat
AsterSwitched for you when the account is flat
Bitget ClassicSwitched for you
Bitget Unified (UTA), Bitunix, WEEXSet it yourself in the exchange's futures settings

If you switch an account to One-Way while bots are running, you get HEDGING DISABLED; switching back gives HEDGING RE-ENABLED.
