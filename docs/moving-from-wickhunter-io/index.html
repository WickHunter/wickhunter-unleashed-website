Getting started

Moving from wickhunter.io

Switch from the original Wick Hunter to Unleashed without two systems trading one account.

Unleashed is a new platform. Accounts and bots are set up again; nothing is imported from wickhunter.io.

Warning. Run only one system per exchange account. Two systems managing the same positions conflict: orders get cancelled or duplicated, and positions and deal counts look wrong in both.

Switch over safely

  1. In wickhunter.io, turn off every bot that trades the account.
  2. Delete the old API key in wickhunter.io and on the exchange.
  3. Decide what happens to positions that are still open:
    • let them close first, then start Unleashed, or
    • let the Unleashed Manual Bot take them over (it adds its own ladder, take profit and stop).
  4. Create a new API key for Unleashed only, restricted to your server's IP.
  5. Connect your exchange and set up your bots fresh. Start small.

Deleting an API key does not close any position or cancel any order. Check the exchange directly after switching.

Settings and subscriptions

  • Bot settings from wickhunter.io do not carry over. Use the bot pages in this guide and the videos to rebuild them.
  • For questions about an existing wickhunter.io subscription, contact Support.
