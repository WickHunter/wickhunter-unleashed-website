Getting started

Connect your exchange

Supported exchanges, API key permissions and the credentials each one needs.

Connect Bybit Securely | Wick Hunter Course 23:01 · Watch on YouTube ↗

Connect each exchange account once under Accounts → Add account, then tick the markets it should run. Every market you tick is checked separately.

API key checklist

  • Create the key on the exchange's official website, on your main account (sub-accounts are not supported on Bitunix, Aster and WEEX).
  • Permissions: read and trade only. Never enable withdrawals or transfers.
  • Restrict the key to your server's public IP address where the exchange allows it.
  • Use a live account key. Demo and testnet keys are not supported.
  • Never paste keys into chat, screenshots or support messages.

Hedge Mode

Every bot needs the account in Hedge Mode. See Hedge Mode for who switches it on each exchange.

What validation means

  • A green card means the key works for that market.
  • A ⚠ on the card names the problem (permission, IP allowlist, Hedge Mode). The account still saves; fix it on the exchange, then ✎ Edit → Save to check again.
  • "The exchange rejected these credentials" means the exchange refused the key. Saving again unchanged fails the same way.

When the exchange locks your account

When the exchange locks your account. A banner such as "WEEX has locked this exchange account…" means the exchange itself restricted the account. Only the exchange can lift it (on WEEX, contact WEEX support); a new API key will not help. Trading on that account is paused, so manage open positions on the exchange directly. After the exchange confirms the unlock, reconnect under Accounts (✎ Edit → Save).

Running more than one account

You can connect as many accounts as you like, each with its own keys and markets. Every running account's API keys are decrypted together and held in memory for the life of the process, so accounts you keep separate on the exchange are not separate here. Secure the server accordingly.

Removing an account

Removing an account deletes its stored keys and stops its markets. It never closes positions or cancels orders. If anything is still open, you are shown what and asked to confirm.
