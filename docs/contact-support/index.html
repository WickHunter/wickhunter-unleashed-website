Support

Contact Support & report a bug

Ask Support a question, or send a bug report with diagnostics attached.

Ask Support

Where your app shows the Support chat button in the corner, open it (Wick Hunter Support) and ask in plain words; answers point to the relevant guide page. If your question isn't resolved, choose Need more help to ask the team for a reply. You can also use Support on the website.

Send a bug report

Use this for anything that looks wrong with trading, P&L or updates.

  1. Open Send feedback in the sidebar (on a phone: More → Send feedback). This opens Report a bug / Request a feature.
  2. Describe what you expected and what happened, with the pair and roughly when.
  3. Optionally add a screenshot (PNG, JPEG or WebP). Screenshots go here, not in Support chat.
  4. Send it while the problem is still visible.

Recent Activity, your selected account and market, and a summary of open deals are attached automatically. API keys, secrets and other credentials are removed before anything is sent.

Keep secrets private

Never send API keys, secrets, passphrases, wallet private keys, your licence key, install link or dashboard password, in chat, email or screenshots. Support will never ask for them.

Feature requests

Use the same Send feedback form and choose Feature.
