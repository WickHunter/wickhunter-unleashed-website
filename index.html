Install guide

From checkout to a running bot in about ten minutes.

Unleashed installs on a server you control. There is no shared infrastructure and no download page to hunt for — everything after checkout arrives by email.

Prerequisites

• A VPS with 1 GB of memory or more
• Ubuntu 22.04 or newer
• A supported exchange account
• An API key with trade permission only
Updates are signed and applied from inside the app — you never re-run the installer to upgrade.
1

Buy

Checkout is a standard card payment through Stripe. No account creation, no manual invoicing.

Card checkoutInstant receiptLicence issued immediately
2

Open your personal install page

We email a private link that is unique to you. It walks you through the rest of setup and is never shared with anyone else.

Delivered by emailPrivate linkOne-time token
3

Run the one-line command

On a fresh Ubuntu 22.04+ VPS, paste the command from your install page.

$ curl -fsSL https://…/install/<your-token> | sudo bash
✓ installs Node, the signed Unleashed release, and HTTPS — prints your dashboard URL in about 3 minutes
4

Add restricted exchange API keys

Create trade-only credentials on your exchange, disable withdrawals, and apply an IP allowlist where the exchange supports it. Start in demo before trading live.
